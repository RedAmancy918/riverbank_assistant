# RiverBank Edge 批量部署待办

当前基线：**RiverBank Edge OS v0.26.6 beta**
目标：把单台验证设备演进为可复现生产、直接烧录、可安全升级和恢复的 RiverBank Edge 整机。

## 已具备

- [x] RiverBank 自有源码使用 Apache License 2.0，品牌与 Logo 保持独立授权；
- [x] 硬件、Edge OS、iOS、macOS/Windows 和工坊应用使用独立版本边界；
- [x] `config/version-catalog.json` 管理发布列车和兼容范围；
- [x] Edge OS 发布管理器封存组件、服务、文件大小和 SHA-256；
- [x] GitHub CI 校验版本、敏感信息、Python、iOS 和桌面客户端构建；
- [x] 设备端账号、Chat、任务、附件和报告保持本地优先；
- [x] 用户创建或导入的工坊应用由 Git、发布扫描器和 OTA 策略强制排除；
- [x] 首次配置已具备手机扫码承载 Wi-Fi、设备名、账号和模型密钥的服务边界；
- [x] 断网恢复、服务一键恢复、日报补跑和健康检查已进入正式链路。

## 镜像与硬件

- [ ] 锁定 Raspberry Pi 5、DSI 屏、摄像头、六麦、Hailo-8 与 NVMe 的量产硬件矩阵；
- [ ] 固定 EEPROM、Linux 内核、固件、HailoRT、PipeWire、Wayland 和关键系统包版本；
- [ ] 建立基于 `pi-gen` 或 Debian 镜像工具的可复现 arm64 构建；
- [ ] 产出不含账号、日志、SSH Host Key、Tailscale 身份和模型密钥的 `.img.xz`；
- [ ] 在空白 SD 和 NVMe 上完成从零烧录测试；
- [ ] 为每台设备建立序列号、设备证书、硬件 Revision 和配置清单，不分叉源码。

## 分区、升级与恢复

- [ ] 实现 `boot + root-a + root-b + data + recovery` 分区方案；
- [ ] Edge OS 根文件系统使用只读或 dm-verity 等价完整性保护；
- [ ] OTA 只写非活动槽，重启健康检查失败自动回滚；
- [ ] 升级、回滚和恢复不得擦除用户 `data` 分区；
- [ ] 生成并签名镜像清单、SHA-256、SPDX SBOM 和来源证明；
- [ ] 支持内部、灰度、全量三个发布环以及远程停止发布；
- [ ] 设计断电发生在下载、写盘、切槽、迁移各阶段时的恢复测试。

## 安全与身份

- [ ] 使用离线根密钥或 KMS/HSM 管理发布签名，设备只保存验证公钥；
- [ ] 每台设备生成独立设备身份和可撤销升级资格，禁止共享万能配对令牌；
- [ ] 生产设备默认关闭密码 SSH、调试端口和不必要的公网监听；
- [ ] 明确第三方素材、字体、模型、Linux/Debian 包的许可证与源码提供义务；
- [ ] 出厂重置清除用户数据和设备密钥，同时保留可信恢复入口；
- [ ] 公司 OTA 服务与本地用户账号分域，设备离线运行不得依赖公司账号中心。

## 自动化与制造

- [ ] 将现有部署脚本拆分为“镜像构建期”和“设备首次启动期”；
- [ ] 建立工厂刷写、序列号注入、硬件探测和最终验收流程；
- [ ] 模型和大体积素材由签名制品仓库分发，不进入 Git；
- [ ] 为系统包、模型、配置和数据迁移建立兼容矩阵；
- [ ] 建立设备升级成功率、回滚率和硬件故障统计，默认不上传用户内容；
- [ ] 为稳定版本定义支持周期、CVE 响应时限和紧急撤回机制。

## 整机验收

- [ ] 冷启动全程不露 Linux 桌面，Plymouth、接力层、自检和表情连续；
- [ ] 麦克风唤醒、双模型 ASR、Hermes、流式 TTS 和语义表情正常；
- [ ] 圆屏菜单、番茄钟、性能、音乐、通话、工坊和 SYSTEM 完整回归；
- [ ] 摄像头共享、圆屏相机、Hailo 互斥租约和隐私灯正确；
- [ ] iOS、macOS、Windows 使用隔离账号完成 Chat、附件、任务、报告和视频通话；
- [ ] 断网、低电压、代理失效、NVMe 未挂载和 Hailo 缺失时告警清晰且不会资源失控；
- [ ] 日报采集、当天精读缓存、按需补证、文章问询和产业资讯更新正常；
- [ ] 工坊生成的时钟、仪表、状态、检测和麦克风应用符合 `riverbank.surface/v1`，未知视图在安装前拒绝；
- [ ] 完成 24 小时、7 天和断电循环稳定性测试后，才把通道从 `beta` 提升为 `stable`。

可烧录镜像的完整设计见 `docs/EDGE_OS.zh-CN.md`；日常部署命令见 `docs/DEPLOYMENT.zh-CN.md`。
