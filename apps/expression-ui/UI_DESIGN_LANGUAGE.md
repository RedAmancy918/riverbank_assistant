# RiverBank 圆形界面设计语言

主题名称：`RiverBank Orbital Blue`  
设计令牌：`ui-theme.json`

## 核心规则

1. 物理圆屏优先：所有主要控件以屏幕圆心为几何基准，不按方形画布四角布局。
2. 圆心基准：状态弧以物理圆心布局；主菜单允许使用主题定义的小幅垂直光学补偿，当前为向下 3 mm。
3. 状态朝向：状态项沿圆弧切线横排并朝向顶部中心；左半边使用“文字 → 图标”，右半边使用“图标 → 文字”，文字旋转方向与所在圆弧一致。
4. 圆润端点：条形、弧形、进度和滑块均使用完整圆帽，不使用平切末端。
5. 柔和分界：避免纯蓝与纯黑的锐利切边；使用低对比蓝灰表面、半透明边缘和轻微辉光过渡。
6. 单一强调色：默认界面使用深蓝灰，只有当前选中项、正在调节的数值和活动状态使用亮蓝。
7. 状态色一致：绿色表示摄像头正在被主动使用，红色表示番茄钟正在后台倒计时；两项同时活动时，同一隐私灯以低频红绿交替呼吸。表情桌面及其展开状态栏沿用校准后的右上角位置；相机、相册、音乐、番茄钟、性能、设置等完整功能页统一在圆屏顶部中轴显示同一盏隐私灯，禁止随页面按钮位置漂移。灰蓝表示可用但未连接。功能页可使用有明确语义的局部主题色，例如番茄钟以低饱和番茄红表示专注、叶片绿表示休息。
8. 动效克制：默认过渡 280 ms，采用 ease-out；临时调节界面静置 1000 ms 后恢复。
9. 字体统一：中文和状态文字统一使用 Microsoft YaHei Regular；仅允许功能页主标题使用一套经过许可记录的主题展示字体。番茄钟标题当前使用 OFL 1.1 的 Ma Shan Zheng，其余数据与控件仍使用 Microsoft YaHei。

## 组件约束

- 径向菜单必须居中，扇区不使用硬描边。
- 主菜单只保留高频入口；“应用”进入同构的二级环形菜单。主菜单固定槽默认显示“空位”；在二级菜单滑中应用后继续沿同方向向外推，外侧细弧平滑展开为确认胶囊：未固定应用显示“固定到桌面”，当前已固定应用显示“取消固定”。文字逐字沿弧形基线排布，进入完整外弧、短暂停留并松手后才提交，向内回收则取消；不再用单独扇区清空固定槽。
- 二级应用菜单只允许通过“返回”扇区回到主菜单，不响应左向右返回手势，避免选择右侧应用时发生手势竞争；层级切换使用缓存表面的短交叉淡化，不直接硬切。
- 选中扇区只使用一条外侧装饰弧，弧线两端必须为小圆帽。
- 顶部状态区使用圆弧胶囊造型，端点半径等于控件厚度的一半。
- 图标与文字必须作为一个整体旋转，不能只旋转文字。
- 状态栏重启入口统一使用标准电源符号：下部为顶部开口的 260° 圆弧，上部为独立竖线，圆弧与竖线的所有端点均为完整圆帽；不得再使用带箭头的循环符号，以免与音乐循环模式混淆。
- 音乐页“词”按钮只控制表情主页的歌词叠层，并以高亮/低亮表示开关；歌曲开始播放、手动换曲和自动续播时立即在后台自动搜索歌词，无需进入歌词页，也不设置手动搜索按钮。中央专辑图与播放器内歌词的切换不受该开关影响。
- 一级扇形菜单的中央空心区只显示本地当前时间，固定使用 24 小时制 `HH:MM`；时间不可点击、不承担入口语义，也不得改变中心死区和滑动选项的触摸判定。二级应用菜单中央仍显示“应用”。
- 从二级“应用”菜单进入的应用，点击返回按钮或执行页面定义的返回手势时，必须通过退出动画回到二级菜单，不得直接回到表情桌面；二级菜单的空闲计时从退出动画完成后重新开始。设置、相机等一级菜单功能仍按各自原有层级返回。
- 番茄钟自然完成阶段时显示五次柔和的全屏完成脉冲：专注完成使用番茄红背景，短休或长休完成使用叶片绿背景；每个脉冲从黑底快速渐入完成色，短暂停留后更缓地自然退回黑底，整段约 4 秒。颜色增强时仅将完整计时圆环、主“开始”按钮和时间调节表冠平滑反转为黑色，其余组件保持原有布局与颜色。黑底与满色两张最终画面必须预渲染缓存，动画期间使用 smoothstep 透明度交叉混合，不得逐帧重建复杂图形；自然完成才触发，手动跳过不触发。
- 边缘柔化不能依赖持续高成本模糊；优先使用低透明度多层辉光和抗锯齿。
- 背景虚化仅在界面打开时生成一次，默认强度为 50。
- 新界面必须从 `ui-theme.json` 读取或映射同名设计令牌，不另建颜色和动画体系。
- 番茄钟保持单一中央倒计时、确定性顺时针圆弧和三项底部控制；完整进度圈与倒计时圆弧必须共享相同内外半径、固定阶段主题色和稳定光晕，专注使用番茄红，短休与长休使用叶片绿，开始、暂停和继续不得引起尺寸或色调跳变；调时入口采用与主圆环短引线相连的机械秒表表冠，专注、短休和长休在待开始或暂停时都可长按，主环随后平滑收缩、72 条短刻度淡入，休息阶段的表冠、内环与刻度波使用叶片绿；手指附近的刻度以余弦高度曲线形成连续刻度波，调时态的内环只保留时间，松手确认当前阶段的一次性时长且不自动开始；右上角统计按钮与左侧返回按钮形成视觉对称，今日环图和近 7 天趋势拆成两个圆屏安全页，通过预渲染横向滑动切换，并用底部双点明确当前页；离开页面后计时继续，并在右上角以低频红色呼吸灯表示后台运行；摄像头同时被主动使用时改为红绿交替。
