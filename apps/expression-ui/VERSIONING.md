# RiverBank 版本规范

所有 RiverBank 自有组件的对外显示、状态接口与发布文件统一使用：

`v主版本.次版本.修订号 beta|stable`

示例：

- `v0.3.7 beta`：仍在开发、验证或硬件校准阶段；
- `v1.0.0 stable`：通过完整验收，可作为稳定部署基线。

版本递增规则：

- 主版本：存在不兼容的架构、配置或数据格式变化；
- 次版本：新增向后兼容的功能；
- 修订号：修复问题或进行不改变接口的优化；
- `beta`：功能仍在快速迭代，可能继续调整；
- `stable`：完整回归、自检、重启和实际硬件验收均通过。

禁止省略 `v`、三段数字或发布通道。读取到旧格式（如 `0.3.6`）时，界面会兼容解析并按 `beta` 显示；读取到非法格式时显示 `v0.0.0 beta`，避免出现无法判断通道的版本号。

Linux 内核、Debian、Python 和第三方模型等外部依赖继续显示其上游原始版本，不追加 RiverBank 的发布通道。
